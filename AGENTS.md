# Omni MD engineering rules

This independent repository owns the plugin and portable Markdown core. User instructions take precedence; preserve unrelated working-tree edits. Canonical repositories are `nilo-ggyt/omni-bar`, `nilo-ggyt/omni-plugin-sdk` and `nilo-ggyt/omni-md`.

- Use Rust 1.99.0, edition 2024 and inherited workspace lint gates. Keep source responsibilities concrete: `crates/omni-markdown-core` owns text/vault/presentation algorithms; `crates/omni-md-plugin` owns SDK integration and AppKit adaptation. No host private dependency or second SDK identity is permitted.
- Static native registration requires exact protocol equality. Metadata is resource-free while idle. Allocate documents, AppKit objects, mappings and workers only after activation; release them with the foreground session. Do not introduce runtime discovery, installers, XPC runners, plugin processes, ABI loaders, compatibility adapters or version negotiation.
- All AppKit work and teardown run on the main thread. End mutable borrows before native calls that may reenter callbacks or present modal UI. Retain native weak delegates under the surface owner; queued work uses weak owners and generation checks. Cancel and join foreground search before session release.
- The piece tree is the only canonical text owner. Preserve bounded lazy UTF-16 presentation, scalar-aligned ranges, structural history and no full-document mutable mirror. Save by streaming with revision checks; never silently overwrite external changes or escape canonical vault confinement. Explicit close saves first and leaves the editor usable on failure.
- A close request, `windowWillClose:`, synchronous canonical destruction and actual native deallocation are distinct. A guessed next-queue boundary is not deallocation authority: macOS 27 ordinary NSTextView diagnostics showed a native hysteresis owner surviving that boundary and actually releasing about 0.51 s later. Track unique native identities with public associated deallocation markers; after the last tracked release stack ends, queue exactly one complete weak-graph check. Only passing that check authorizes `finish_close` or a successor. Canonical document/history/mappings and foreground workers still release synchronously. Report observed close/handoff latency honestly. No sleep, retry timer, hidden window, retained inactive session or surviving-node allowance may conceal failure; a probe-only failure deadline may stop an unavailable completion without rechecking or accepting the graph.
- All project-owned documentation/comments use English. Explain modules/types/functions, every internal logical section, each `if`/`else` path and `match` arm, loops/callbacks, failures and resource transitions. Comments explain meaning and constraints, not syntax. Every unsafe block/implementation has a specific adjacent English `SAFETY` justification; unsafe APIs state caller obligations. Exclude upstream/generated content from blanket annotation.
- Run applicable fmt, Clippy, tests, rustdoc, native probes and host assembly checks. Native probes use `harness = false` and no skip/allow flags for acceptance. Report exact observed results; static checks do not prove user-visible behavior or object release.
- Formal acceptance uses Apple M5 Max/36 GiB/macOS 27.0.1; macOS 14 remains the deployment floor. M1/8 GiB and macOS 14 runtime validation stay explicitly untested until measured.
- Preserve MIT attribution to nilo vance and third-party notices. Exclude credentials, generated outputs, caches, temporary path overrides and private task/session traces. Do not automatically stage, commit or push.
